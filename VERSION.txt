工程咨询成果审核工作台
VERSION = 1.2.0
RELEASE = 2026-09-21
CODE    = wb-audit-v1.2

【定位】
石油天然气行业工程咨询成果的 AI 初审平台。内网自托管，面向本单位同事使用。
以 WorkBuddy 训练的「petroleum-engineering-review」专家技能为知识内核，外面套一层
分阶段审核流水线 + 内网 Web 服务。

【v1.2.0 相对 v1.1.0 的变化】
新增
· PPT 审核：可上传 .pptx / .ppt，做幻灯片自身审核（单页字数超限、数据无出处、
  前后自相矛盾、编校与单位混用、结论过硬）
· PPT ↔ 报告一致性核对：同一批里含 Word + PPT 时可勾选，核对两边的数据 / 观点 / 内容
· 成果按 PPT 优先排版：PPT 问题放第一部分（其中"与报告不一致"在最前，PPT 自身问题在后）
· 只传 PPT 也可提交（仅做 PPT 自身审核；没有对照报告就不做一致性核对）
· 截图型 PPT 识别：提取文字过少时明确告知"系统不做图片 OCR，只能做有限校对"
· 技能新增《PPT 汇报材料审核专项》WB-ADD 块（第 5 块）
修复
· 暂存文件没保留扩展名导致转换失败
· 创建任务时的重复落盘把"已配对 PPT"进度抹掉
· PPT 板块作用域错（校对成果与审核成果是两个函数）

【v1.1.0 相对 v1.0.0 的变化】
新增

· 成果下载改 PDF（浏览器打印引擎，版式与页面一致），补充审核也出 PDF

· S2 用量漏记（费用低估到约 1/5）
· 项目台账只增不减（改为从任务实时派生）

【这一版包含什么】
· 审核引擎：S0 预审 → S1 结构化 → S2 八单元分维度 → S3 规则校验（纯代码）
            → S4 分级闸门（纯代码）→ S5 仅叙述，附录由代码生成
· 两类成果：校对成果（人人可看）/ 审核成果（管理员 + 审核专家）
· 自动识别：报告类型、项目类型（无需人工选择）
· 调度：闲时/忙时计费感知，预处理本地做、AI 调用推闲时
· 数据看板：次数与用量、闲时占比与省钱测算、问题按项目类型分布、API 费用口径、项目质量台账
· 补充审核：管理员针对指定要点发起定向深入核查，每轮单独出意见
· 重复审核提醒：同一项目被他人重复提交时暂停等确认
· 登录防护：限流 + 阶梯验证码 + 锁定，管理员可一键解除
· 技能沉淀：人工反馈 → LEARNED.md，不触碰 WorkBuddy 原件。作用域三档（全局/按报告类型/指定项目）；
  一条经验可挂多个类型或项目；**生成前先做 AI 融合审阅**（新增/细化/冲突/重复判定 + 多条候选口径，人工勾选后才写入）
· 运维：开机自启、崩溃重启、5 分钟自愈看门狗、每周自动备份

【运行依赖】
