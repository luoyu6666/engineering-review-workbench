使用帮助

      
    

    

      1. 怎么提交报告？

      左上角「提交审核」→ 选报告类型 → 把 Word 拖进虚线框 → 点「提交审核」。


      2. 为什么只能用 .docx / .doc，PDF 不行？

      PDF 转成文字后表格结构会全部丢失，而投资对比表、成功度评分表、变更清单这些问题全在表格里。传 PDF 会漏掉最关键的投资类、评分类问题。请传 Word 原件。


      3. 要等多久？

      一般 2~3 分钟，10 MB 以上大报告 3~5 分钟。同时只处理 2 个任务，排队时会显示「队列第 N 位」。

      可以关掉页面，稍后回来看，任务在服务器上跑。


      4. 成果报告怎么看？

      🔴 P0 必须修改——不改则报告不具备上报条件；⚠️ P1 建议修改——编校、术语、AI套话等，不影响上报。

      每条 P0 都带「原文定位 / 判定依据 / 修改建议」，可以照着改。

      报告分两种：校对成果（编校、术语、AI套话、数据不实、口径混用等可自行核对的问题）人人可看；
      审核成果（另含逻辑、结论、投资、建议等专业判断）仅管理员与审核专家可看。

      点「下载 Word」可导出后直接发给编制单位。


      5. 任务失败了怎么办？

      点开那条任务，看「处理日志」里的红字。常见原因是文件损坏或带只读属性。修好后重新提交一次即可。


      6. 审核结果和我判断不一样？

      AI 只是初审，不能替代专家终审。发现误报（把没问题的地方报成 P0）或漏报，请告诉管理员——这些反馈会用来改进审核规则，误报比漏报更需要及时反馈。


      7. 报告内容安全吗？

      报告和结果都存在公司内网服务器，只通过内网访问。审核时报告内容会发送到云端大模型做分析。
