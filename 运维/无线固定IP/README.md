# 无线固定 IP —— 分发给同事的材料

## 给同事发什么

**4 个文件放在同一个文件夹里**（缺一不可），打包发给他们：

| 文件 | 作用 |
|---|---|
| `无线固定IP操作手册.pdf` | 图文操作手册（先看这个） |
| `设置固定IP.bat` | 双击即可固定 IP（内部会调用下面的 ps1） |
| `改回自动获取IP.bat` | 出差/回家上网前双击这个 |
| `net-ip-set.ps1` | 脚本本体；**必须和两个 .bat 放一起** |

也可以直接把整个文件夹压缩成 zip 发出去。

## 同事要做的三步

1. 连上单位无线 → 双击 `设置固定IP.bat` → 点"是" → 输入 `Y` 回车；
2. 把窗口里显示的 **IP 地址**报给管理员（只需报一次）；
3. 出差/回家前双击 `改回自动获取IP.bat`，回单位后再运行一次 `设置固定IP.bat`。

## 管理员要做的

收到 IP 后：系统管理 → 访问控制（全局白名单）加入该 IP，或在用户管理里绑定到该同事账号（会自动并入白名单）。
建议用手册最后一页的登记表留痕。

## 已做的验证（2026-10-09）

- 脚本在服务器上实跑（无无线网卡）：安全提示"没找到无线网"并退出，**有线网卡未被改动**；
- 参数读取与**掩码换算**已实测：`10.81.108.161 /24 → 255.255.255.0`（原先用 32 位有符号位移会算出空值，已改用 Int64）；
- `.ps1` 存为 **UTF-8 带 BOM**（否则 PowerShell 5.1 会把中文读成乱码）；
- 手册 PDF 已逐页目视检查排版。

## 注意事项

- **没在真机上执行过"写入固定 IP"那一步**（服务器没有无线网卡，且不能动现有网络）。建议先让 1～2 位同事试，确认无误再群发；
- 网线与无线是两张网卡，脚本只改**无线**网卡（按 802.11 类型自动识别）；
- 手册里的界面图为**示意图**（按位置绘制），实际界面随 Windows 版本略有差异。
