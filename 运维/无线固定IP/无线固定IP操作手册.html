把无线网络设成固定 IP
一次设置，长期有效 —— 不用再找管理员改白名单
这份手册解决什么问题？
无线网络默认「自动获取 IP」，每次开机会换一个新 IP；
审核系统的访问白名单里没有新 IP，就打不开审核工作台。

把当前 IP 固定下来，再报给管理员登记一次，以后永远不用再报。
（两个办法：① 一键脚本，30 秒；② 手动点选，附图文。任选其一即可。）

做法一（推荐）：双击一个文件就好

你会用到两个文件：
设置固定IP.bat —— 把无线 IP 固定下来（第一次用这个）
改回自动获取IP.bat —— 出差、回家上网前用（在学校/单位以外的地方）
两个文件要放在同一个文件夹里；文件名请勿改动。
第 1 步　先连上单位无线网
点右下角网络图标，连上单位无线（就是平时上网那个）。确认能打开网页。
第 2 步　双击「设置固定IP.bat」
会弹出「用户账户控制 / 你要允许此应用对你的设备进行更改吗？」→ 点 是。

提示"没找到无线网卡"？说明此刻没连无线——先连上无线网再双击脚本。

常见问题 / 检查是否成功

1. 怎么确认已经固定成功了？

  • 再次双击「设置固定IP.bat」，看「当前 IP」是否与你报给管理员的那个一致；
  • 或者重启电脑后打开审核工作台，能正常登录即成功。

2. 改完上不了网怎么办？

  • 先双击「改回自动获取IP.bat」输 Y 回车，恢复原样；
  • 还不行就把窗口截图发给管理员（可能是网关/DNS 与本单位不一致）。

3. 换了一台电脑 / 换了无线网卡？

  • 新电脑重复本手册第 1～4 步，把新 IP 报管理员登记一次即可。

4. 会不会影响别人？

  • 脚本只把你当前拿到的那个 IP 固定下来，不会去抢别人的号；
  • 万一提示"IP 已被占用"，把当前自动获取到的另一个 IP 固定即可，或联系管理员。

5. 为什么不能自己随便编一个 IP？

  • 编错了（比如网关、掩码写错）会直接上不了网；用本手册的做法最省事。

给管理员的一页

登记流程（每台电脑只做一次）
  1. 收到同事报来的固定 IP（形如 10.81.109.x）；

  3. 回复同事"已登记"，请其重启验证一次。

技术备注（给管理员）：脚本读取网卡当前 DHCP 参数（IP / 前缀长度→掩码 / 网关 / DNS）后用 netsh interface ip set address … static 写回；网卡自动识别为 802.11 无线网卡，有线网卡不受影响。 掩码由前缀长度换算（用 Int64 计算，避免 32 位溢出导致 255.255.255.0 算成空值）。 手册中的"界面示意图"为绘制图，用于指示位置，实际界面随 Windows 版本略有差异。
